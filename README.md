1. Pengertian Bootstrap
Bootstrap adalah framework CSS yang digunakan untuk mempermudah pembuatan tampilan website.
Bootstrap menyediakan berbagai class yang dapat digunakan untuk mengatur tampilan elemen seperti tombol, form, warna, dan tata letak tanpa harus menulis semua kode CSS dari awal.
Bootstrap juga membantu membuat website yang responsif sehingga tampilannya dapat menyesuaikan ukuran layar perangkat.
2. Cara pasang Bootstrap
Bootstrap dapat dipasang dengan dua cara, yaitu menggunakan CDN dan file lokal.
Penggunaan CDN dilakukan dengan menambahkan tautan Bootstrap pada file HTML sehingga file Bootstrap dapat dimuat melalui internet.
Sementara itu, penggunaan file lokal dilakukan dengan mengunduh Bootstrap terlebih dahulu, kemudian menghubungkan file tersebut ke dalam proyek website.
Kedua cara tersebut dapat digunakan sesuai kebutuhan pengembangan website.
3. Grid dan Breakpoint
Grid pada Bootstrap merupakan sistem yang digunakan untuk mengatur tata letak konten dalam bentuk baris dan kolom.
Sistem ini membantu membagi halaman menjadi beberapa bagian agar susunannya lebih teratur.
Sementara itu, breakpoint adalah batas ukuran layar yang menentukan kapan tata letak website menyesuaikan diri.
Dengan adanya grid dan breakpoint, tampilan website dapat dibuat responsif untuk perangkat seperti HP, tablet, dan laptop.
4. Class Bootstrap dan kegunaannya
a. container memiliki kegunaan membuat wadah untuk menampung konten website dengan lebar yang menyesuaikan ukuran layar.
b. text-center memiliki kegunaan mengatur posisi teks agar berada di tengah secara horizontal.
c. btn memiliki kegunaan memberikan tampilan dasar pada elemen tombol agar terlihat lebih rapi.
d. form-control memiliki kegunaan memberikan tampilan Bootstrap pada elemen input, seperti kolom username dan password.
e. shadow memiliki kegunaan menambahkan efek bayangan pada elemen, misalnya kartu login, agar terlihat lebih menonjol.
5. Gambar Responsif
Bootstrap menyediakan class img-fluid untuk membuat gambar menyesuaikan lebar wadahnya.
Class ini membuat gambar memiliki lebar maksimum sebesar wadah dan tinggi yang menyesuaikan secara otomatis, sehingga gambar tidak melebar melebihi wadahnya ketika ukuran layar berubah.
Class tersebut dapat ditambahkan langsung ke elemen gambar HTML.
Contoh: <img src="gambar.jpg" class="img-fluid" alt="Contoh gambar">
